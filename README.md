# PROJECT OVERVIEW
This project focused on performing comprehensive data cleaning and exploratory data analysis (EDA) on an electronics product dataset using SQL. The primary objective was to transform raw, unstructured product records into a clean, structured format and uncover key insights regarding pricing, ratings, and brand distribution. Using advanced SQL queries, the workflow included handling missing values, parsing and cleaning text-based currency and pricing ranges, engineering new features such as MRP and discount types, and extracting structured numerical ratings and brand names via regular expressions.
The exploratory data analysis phase investigated univariate distributions, price outliers using interquartile ranges, and statistical summaries. Furthermore, bivariate and multivariate analyses explored relationships between product pricing, review counts, ratings, and brand performance. This analysis provides actionable insights into market pricing strategies, product consistency, and consumer engagement patterns.
